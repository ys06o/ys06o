### 03. OurAssembly

**국회의원 활동 정보 제공 플랫폼**

공공데이터를 기반으로 사용자가 지역 정치인 정보를 확인하고 관심 정보 알림을 받을 수 있는 서비스입니다.  
인증, 스케줄링, 알림 기능을 중심으로 백엔드 기능을 구현했습니다.

![Spring Boot](https://img.shields.io/badge/Spring%20Boot-6DB33F?style=flat-square&logo=springboot&logoColor=white)
![MySQL](https://img.shields.io/badge/MySQL-4479A1?style=flat-square&logo=mysql&logoColor=white)
![Firebase](https://img.shields.io/badge/Firebase-FFCA28?style=flat-square&logo=firebase&logoColor=1F2937)

**Role**

- 백엔드 개발
- API 설계 및 데이터 처리

**Backend Focus**

- JWT 기반 인증 기능 구현
- Scheduler를 활용한 데이터 처리
- Firebase FCM 기반 관심사 알림 기능 구현
- 공공데이터 활용을 위한 REST API 설계
