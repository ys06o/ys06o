## 프로젝트

### 우리동네 국회의원
위치 기반으로 지역구 국회의원 정보를 확인할 수 있는 서비스입니다.  
공공데이터 API를 활용해 지역별 의원 정보를 조회할 수 있도록 구현했습니다.

- Backend: Spring Boot, MySQL
- 주요 기능
  - 지역 기반 국회의원 조회
  - 공공데이터 API 연동
  - REST API 설계 및 데이터 처리
  - 예외 처리 및 응답 구조 구성

<br/>

### PlantCare
식물 관리 서비스를 주제로 진행한 팀 프로젝트입니다.  
식물 등록, 성장 기록, 센서 데이터 확인 기능 등을 구현했습니다.

- Backend: Spring Boot, MySQL
- 주요 역할
  - 백엔드 API 개발
  - DB 설계 및 데이터 처리
  - 센서 데이터 연동 구조 구현
