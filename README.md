## Problem Solving

프로젝트를 진행하면서 서비스의 기반 구조와 운영 안정성을 높이기 위한 고민을 정리하고 있습니다.

| Topic | Focus |
| --- | --- |
| JWT 기반 인증 구조 설계 | 사용자 인증 흐름, 토큰 검증, 보안 처리 |
| Redis를 활용한 데이터 처리 | 인증 정보, 캐싱, 빠른 데이터 접근 |

| 데이터베이스 모델링 | 서비스 흐름에 맞는 테이블 관계와 제약 설계 |
