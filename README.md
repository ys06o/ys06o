# 김용성

### Java와 Spring Boot로 서비스의 기반을 설계하는 백엔드 개발자

기능을 빠르게 붙이는 것보다, 인증 구조와 데이터 모델, API 흐름이 안정적으로 맞물리는 서비스를 만드는 데 관심이 있습니다.  
프로젝트에서는 기획부터 설계, 백엔드, 프론트엔드 연동까지 경험하며 사용자가 실제로 쓰는 기능을 끝까지 완성해왔습니다.

**공간 기반 디지털 방명록 서비스**
