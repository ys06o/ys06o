## 소개
신뢰성과 확장성을 갖춘 서버 사이드 시스템을 만드는 백엔드 개발자 **김용성**입니다.  
Java/Spring Boot 기반의 첫 정규직 백엔드 개발 포지션을 준비하고 있습니다.

## 기술 스택
| Backend | Database | DevOps & Cloud | Frontend | Tools & Collaboration |
|---|---|---|---|---|
| Java, Spring Boot | MySQL, MariaDB | AWS (EC2, S3) | React, JavaScript | Git, GitHub |
| Spring Security | Redis | Firebase (FCM), Gmail SMTP | HTML5 / CSS3 | IntelliJ IDEA, VS Code, Eclipse |
| Spring AI, OpenAI API |  | Docker, GitHub Actions | React Native | Notion, Figma |
