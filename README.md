## About

- Java와 Spring Boot를 중심으로 백엔드 개발을 공부하고 있습니다.
- REST API, JWT 인증, 데이터베이스 설계처럼 서비스의 기반이 되는 영역에 관심이 많습니다.
- 프로젝트에서 기획, 설계, 백엔드 개발, 프론트엔드 연동까지 경험했습니다.
- 협업 과정에서 기능 구현뿐 아니라 API 명세, 이슈 정리, 기록을 중요하게 생각합니다.

<br />

## Main Project

### 여기남김

> 공간에 추억을 남기고 함께 기록할 수 있는 디지털 방명록 서비스

`여기남김`은 단순 게시판이 아니라, 사용자가 만든 보드 위에 기록의 위치를 저장하고 친구를 초대해 함께 추억을 남길 수 있는 서비스입니다.

**Role**

- 서비스 기획
- 백엔드 API 설계 및 구현
- 프론트엔드 화면 연동
- 배포 구조 구성

**What I Built**

- JWT 기반 사용자 인증 흐름
- 보드 생성, 조회, 수정 기능
- 커스텀 보드 위 좌표 저장 구조
- 친구 초대 및 참여자 관리 흐름
- 프론트엔드 사용 흐름에 맞춘 REST API

**What I Focused On**

- 보드, 기록, 참여자 사이의 관계를 어떻게 나눌지 고민했습니다.
- 좌표 기반 데이터를 저장하고 다시 화면에 렌더링하기 쉬운 구조를 설계했습니다.
- 초대 링크를 통해 사용자가 자연스럽게 서비스에 진입하는 흐름을 고민했습니다.
